Proof from the chain

This page checks every on-chain claim JalSaakshya makes. It runs in your browser and reads Arkiv Tiramisu directly. It uses no server of ours, and nothing on this page is pre-computed: each number is counted or queried live, and each check links to the transaction or address you can inspect on the explorer.

The same checks run from a terminal: git clone https://github.com/mohitt31/jalsaakshya; cd jalsaakshya/web; npm ci; npm run verify

Checking…

What these checks do not prove: that a kit was used correctly, or that the water came from the source named. A signature proves which wallet published a reading and when. See trust boundaries.
