No server: this page reads Arkiv directly. Survey records are shown only if their on-chain creator is the curator wallet , and they are read-only.

(0)

    • Rows come from CGWB and state groundwater reports and published studies. Each row was re-found on its PDF page before publishing; rows whose unit is not printed on the page were left out.
    • A curator wallet published them as read-only Arkiv entities. Anyone can write an entity with the same attributes, but only the curator's entities carry its $creator, which is what this page filters on.
    • Field tests are separate entities that expire after 90 days. Anyone can extend one by confirming it, so a report survives only while people keep re-testing.
    • The data contract is in arkiv/schema.md: any app can query the same entities without us.

    Limits used: arsenic 0.01 mg/L, fluoride 1.5 mg/L (IS 10500:2012). Research evidence, not household safety advice. Source code (MIT)
